# Cloudflare Worker 部署说明

这个 Worker 只负责图片生成，Netlify 不再保存 Cloudflare Token。

## 方式一：后台手动创建

1. 打开 Cloudflare Dashboard。
2. 进入 `Workers & Pages`。
3. 新建 Worker，名称建议：`design-workbench-image`。
4. 把 `worker.js` 的内容复制进去。
5. 在 Worker 设置里添加 Workers AI 绑定：
   - Binding name: `AI`
6. 部署后复制 Worker 访问地址，例如：
   - `https://design-workbench-image.xxx.workers.dev`
7. 把这个地址发给我，我会写入 Netlify 的 `IMAGE_WORKER_URL` 并重新部署网站。

## 方式二：给新的 Cloudflare API Token 自动部署

如果想让我自动部署，需要新 Token 至少有：

- Workers Scripts: Edit
- Workers AI: Edit
- Account Settings: Read

当前 Token 不能创建 Worker，Cloudflare 返回了鉴权失败。
