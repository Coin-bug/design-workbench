# UI/UX AI 设计工作台一期需求

## 产品定位

面向 UI/UX 体验设计师的本地网页工具合集。先服务个人工作流，成熟后再产品化给别人用。

一期只做三个入口：

| 工具 | 目标 |
|---|---|
| 竞品分析助手 | 输入目标和需求，生成给 Codex 的联网研究指令；将 Codex 结果贴回网页展示 |
| 风格方向延展 | 上传真实图/线框图/规范图和参考图，生成 3 套 AI 出图任务；将模型结果上传回网页展示 |
| 设计核查助手 | 上传设计稿和线上截图，按历史核查模板输出像素级差异结果 |

## 实现约束

- 本地部署，网页完成。
- 一期不接 Figma。
- 允许联网调用便宜 AI API，但 key 不写死在项目里。
- 竞品分析今天先由 Codex 联网执行，网页负责生成指令和展示结果。
- 风格延展今天先由外部图像模型执行，网页负责生成出图任务和展示结果。
- API 不可用时，页面仍要能完成本地核查。

## 优先级

| 优先级 | 功能 | 标准 |
|---|---|---|
| P0 | 设计核查 | 能真实比较两张图，并按模板输出结果 |
| P1 | 风格延展 | 能生成 3 套可直接给图像模型使用的出图任务，并展示模型结果 |
| P2 | 竞品分析 | 能生成 Codex 联网研究指令，并展示 Markdown 报告 |
| P3 | 历史记录和批量能力 | 后续迭代 |
