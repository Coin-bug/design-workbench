# 本地设计灵感工作站一期需求

## 产品定位

面向 UI/UX 设计师的本地资料工作台。先解决个人设计资产散落的问题，把提示词、参考图、色板和项目上下文集中到一个浏览器页面里。

## 实现约束

- 本地部署，网页完成。
- 不调用 API，不上传图片，不需要填写 key。
- 数据保存在当前浏览器本地存储。
- 页面第一屏就是可用工作台，不做营销落地页。
- 设计风格偏深色设计档案室：清楚、克制、耐看，适合长期整理资料。

## 一期模块

| 模块 | 目标 |
|---|---|
| 提示词收藏夹 | 保存提示词、参考图/结果图、标签和归属项目，支持搜索、复制、删除 |
| 灵感板 | 批量保存参考图，记录喜欢的构图、配色、质感或信息层级 |
| 配色收藏 | 从图片提取主色，或手动维护 HEX 色值，支持一键复制 |
| 项目资料夹 | 记录项目摘要与阶段，并统计关联的提示词、灵感图和色板 |

## 准出标准

| 自检项 | 通过标准 |
|---|---|
| 本地可用 | 断网也能新增、搜索、复制、删除和导出备份 |
| 无接口依赖 | 前端不请求业务 API，启动脚本只提供静态文件 |
| 信息清晰 | 四个模块入口明确，表单和资料卡能被设计师直接理解 |
| 视觉完整 | 深色工作台、清晰层级、响应式布局、空状态齐全 |
| 数据闭环 | 新建项目后可在其他模块归档，并能在项目卡看到统计 |
