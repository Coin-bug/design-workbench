# 一键核查风格.md

## 文件作用

这是「设计核查助手」的唯一展示风格约束文件。所有核查结果在准出前，必须以本文件和核查模板为准进行自检。

## 核心风格

- 深色画布
- 大色块封面
- 蓝色代表视觉核查
- 橙色代表动效核查
- 三列对比：设计稿、线上还原、问题区
- 问题卡片必须直接、清楚、能改
- 红色用于差异标注
- 状态必须明确：已验证、待修复、待评估

## 视觉规则

| 元素 | 规则 |
|---|---|
| 背景 | 主体使用接近黑色的深色画布 |
| 侧栏 | 视觉核查使用蓝色，动效核查使用橙色 |
| 截图 | 设计稿和线上截图必须同尺寸并排展示 |
| 标注 | 差异区域使用红色半透明覆盖或红框 |
| 文案 | 大白话说明，不写空泛描述 |
| 状态 | 无差异写“验证通过”，有差异写“待修复” |

## 控件清单

| 控件 | 用途 |
|---|---|
| Audit Cover | 核查封面 |
| Audit Board | 单页核查看板 |
| Compare Column | 设计稿/线上截图列 |
| Issue Card | 单条问题 |
| Priority Badge | P0/P1/P2/P3 |
| Annotation Overlay | 差异标注 |
| Status Stamp | 已验证/待修复/待评估 |
| Self Check | 准出自检 |

## 优先级规则

| 优先级 | 判断标准 |
|---|---|
| P0 | 核心流程、核心内容、核心视觉明显错误，影响上线或验收 |
| P1 | 明显影响设计还原，肉眼一眼可见 |
| P2 | 中轻度还原问题，比如间距、字号、颜色、圆角等偏差 |
| P3 | 很细的优化项，比如 1-2px 偏差、非核心细节 |

## 准出标准

| 自检项 | 通过标准 |
|---|---|
| 风格一致性 | 深色画布、三列结构、问题区、状态区齐全 |
| 字段完整性 | 模块、差异点、设计稿表现、线上表现、优先级、修改建议、状态齐全 |
| 差异真实性 | 不凭空编造问题 |
| 模板匹配度 | 达到 95% 以上 |
| 准出结论 | 明确写出是否可以准出 |
